## B. 화면 설계 확정성 (design.md)

- [x] **B1. 세 핵심 화면의 정보 구조가 정의되어 있는가**
  근거: design.md 3절이 세 화면의 블록 구조와 **정보 우선순위 목록**을 각각 제시하고 비목표까지 명시.
  4절이 화면별 최대 폭·여백·열 구성을 수치로 확정.

- [x] **B2. 디자인 토큰을 실제 CSS로 변환하는 계획이 있는가**
  근거: design.md 15절에 토큰 전체가 이름·값으로 있고, plan.md 3절이 `src/styles/tokens.css`로 옮기는
  방법과 **하드코딩 색을 stylelint로 차단**하는 강제 수단, `scripts/contrast.ts`로 대비를 재계산해
  기준 미달 시 빌드를 실패시키는 절차를 명시.
  `--ink800` 미사용 정리, `--focusDark` 분리까지 반영됨.

- [x] **B3. 메인 Hero 시각 효과의 구현 범위가 정의되어 있는가**
  근거: design.md 10절이 Aurora 3광원의 위치·크기·색·투명도, Grid 44px/opacity .06/마스크,
  Scrim 그라데이션 값, Floating Card 규격, **애니메이션 5종 표**를 확정.
  plan.md 5절이 `AuroraBackdrop` 한 컴포넌트로 캡슐화하고 이미지·동영상·Lottie·SVG 파일을 금지.
  성능 예산이 **수치로 확정**됨(효과 자산 ≤100KB, 웹폰트 ≤150KB).

- [x] **B4. prefers-reduced-motion 대응이 정의되어 있는가**
  근거: design.md 22절이 5종 애니메이션 각각의 정지 시 거동을 표로 명시하고
  "정보가 애니메이션에만 담기지 않는다"를 확인. plan.md 7절이 **`motion.css` 한 파일로 격리 + stylelint로
  다른 파일의 `animation` 사용을 차단**하는 강제 수단과 Playwright `reducedMotion:'reduce'` 프로젝트를 규정.

- [x] **B5. Loading · Empty · Error · Unauthorized 상태가 정의되어 있는가**
  근거: design.md 14절이 9개 행(로딩 2·빈 목록 2·오류 2·권한 없음·로그인 필요·저장 중)에 대해
  **표현 방식·정확한 문구·다음 행동**을 확정. plan.md 8절이 `ViewState` 판별 유니온과 `StateBox` 5변형,
  문구 상수 파일(`stateCopy.ts`), 스켈레톤 58px 고정을 규정.

- [x] **B6. 회원과 관리자 UI 차이가 정의되어 있는가**
  근거: design.md 6절이 13개 지점의 역할별 차이를 표로 확정하고, **차이를 "요소의 존재/부재"로 표현하며
  비활성으로 암시하지 않는다**는 원칙까지 명시. 관리자 기본 필터가 `답변 대기`임도 확정.
